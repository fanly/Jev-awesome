# Jev-awesome

A developer-focused reference catalog for **Jev / TypeSafe**: discoverable sources, human curation, and clear limits.

> Unofficial. Not affiliated with TypeSafe. Always verify upstream yourself. 中文主文档：[README.md](README.md)

## Quick start

```bash
uv sync --frozen
uv run jev-awesome doctor
uv run jev-awesome validate
```

Works without `TYPESAFE_API_KEY` in `rules` mode.
